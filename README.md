## 📊 Key KPIs Tracked

This dashboard tracks critical customer performance metrics:

| KPI | Description |
|-----|-------------|
| Total Customers | Total number of unique customers |
| Total Purchases | Total number of transactions |
| Average Income | Average income of customers |
| Average Tenure | Average customer relationship duration |
| Average Satisfaction Score | Overall satisfaction rating |
| Repeat Purchase Rate | % of returning customers |
| Churn Rate | % of customers who stopped purchasing |
| Average Engagement Score | Customer interaction index |

---

## 🧮 KPI Calculation Logic

- Total Customers = COUNT(Customer ID)
- Total Purchases = COUNT(Order ID)
- Average Income = AVERAGE(Customer Income)
- Average Tenure = AVERAGE(Customer Tenure)
- Satisfaction Score = AVERAGE(Customer Rating)
- Repeat Purchase Rate = (Returning Customers / Total Customers) × 100
- Churn Rate = (Inactive Customers / Total Customers) × 100
- Engagement Score = Average customer activity score
